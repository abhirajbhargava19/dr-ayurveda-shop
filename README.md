# 🌿 Dr. Ayurveda Shop

Authentic Ayurvedic products — built by Dr. [Naam], BAMS.

## 🛒 Features
- Product catalog with categories
- Sale / Flash Deals with countdown
- Cart + WhatsApp ordering
- Search (text + voice)
- Sort: Price, Rating, Newest
- Admin Panel (password protected)
- Mobile responsive

## 🚀 How to Run
1. Clone this repo
2. Open `index.html` in browser
3. Or use Live Server (VS Code extension)
